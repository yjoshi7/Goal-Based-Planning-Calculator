Quick Guide to GoalWise

1
Choose a Client Tab
Use Existing Client to search & load a saved plan, or New Client to start fresh.
2
Add a Goal
Select a goal type (Retirement, Education…), fill in the cost, years, and adjust inflation/return if needed. Click Add Goal.
3
See Your Plan
The dashboard shows total future cost, required monthly SIP, and a readiness score. Charts break down your goals.
4
Track Contributions
Log each SIP payment – the tool recalculates remaining shortfall based on the exact date you invested.
5
Edit or Delete
Click the edit icon (✎) to modify a goal, or the delete icon (✕) to remove it. Everything syncs to Google Sheets.
6
Print / Save PDF
Use the print button for a clean, client‑ready report.
